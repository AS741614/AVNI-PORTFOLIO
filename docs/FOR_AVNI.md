# For Avni — quick Instagram setup (≈20 min, free)

Hi Avni! To show your Instagram posts on the new website automatically, we need
one access token from you. Here's all you do:

## 1. Switch your Instagram to a Creator account
In the Instagram app: Settings → "Account type and tools" → "Switch to professional
account" → choose **Creator**. (Free, reversible.)

## 2. Create a Meta app
Open this link (sign in with the Instagram/Facebook login you use):
👉 https://developers.facebook.com/apps/

- Click **Create app**
- Use case: **Other** → app type: **Business**
- Name it: "Avni in Ireland website" → create

## 3. Add Instagram + generate the token
- In the app dashboard: **Add product → Instagram → Set up**
- Choose **"Instagram API with Instagram Login"**
- Connect your Instagram account, approve the permissions
- Copy the **long-lived access token** it gives you

Reference if you get stuck:
👉 https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login

## 4. Send us back
Just send us the **access token** (the long string from step 3).
That's it — we'll plug it in and your posts will appear on the site automatically.

⚠️ The token is like a password for read-only access to your posts — please send it
to us privately (not in any public group).
